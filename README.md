# SE-FI-KA Kuljetus Oy

Finnish-language scrollable business website. Open index.html in a current browser. All assets are included; no installation or build is required. Upload this folder to any static web host to publish it.

## Design and functions

Version 4 replaces the cartoon truck and decorative map with a full-width photographic concept hero, black and neutral gray surfaces, consistent red-orange accents, and an editorial scroll chapter sequence. Typography uses bundled variable Archivo for headings and IBM Plex Sans for supporting text, with revised proportions, spacing, weights and readable labels. Includes mobile navigation, phone and map links, and a transport brief builder with clipboard copying and a manual-copy fallback. Reduced-motion settings disable animation and show all journey steps.

The wordmark is a design concept. The hero image was generated using the built-in ImageGen tool and is labelled as an AI concept image; it does not show the company's actual fleet. See IMAGE-PROMPT.md for the final prompt. No customer testimonials, equipment specifications or guaranteed response times are invented.
